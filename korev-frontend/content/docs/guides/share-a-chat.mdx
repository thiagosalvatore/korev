---
title: Share a chat
description: 'Save a chat as one HTML file and send it to anyone.'
---

Korev runs on your Mac, so a chat has no link to send. Instead, save it as one HTML file. Anyone can open the file in a browser, without Korev.

## Save a chat

1. Open the chat. In a workspace, select its tab. In Ask, open the Ask chat.
2. Press **Share chat**, the share button at the right of the tab bar or in the Ask header.
3. Choose where to save the file.

## What the file holds

- Your messages and the agent's answers, with their formatting.
- Plans and todo lists.
- Each tool call, closed. Open one to see its command or, for an edit, the lines it changed.
- The agent, the model, the repository, the branch and the date the chat started.

The file leaves out tool output and the agent's thinking, because they can hold secrets such as environment values. Attached images show only their file name.

Tool calls still show the commands and edits themselves. Read the file before you send it.

The file has no scripts. It follows the reader's light or dark setting.
