## An agent shows "Not installed"

Korev looks for `claude` and `codex` on your login shell's PATH, plus `~/.local/bin`, `~/.npm-global/bin`, `~/.bun/bin`, `/opt/homebrew/bin` and `/usr/local/bin`. Check that `claude --version` or `codex --version` works in a new terminal window, then restart Korev.

## macOS says Korev can't be opened

Releases from 0.3.0 on are notarized and open without this message. Download the [latest release](https://github.com/thiagosalvatore/korev/releases/latest). An older release, or a build you made yourself, is not notarized. Open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**. Or run `xattr -dr com.apple.quarantine Korev.app`.

## "Setup script failed"

Open the **Setup** tab in the terminal panel to see the output. Fix the script, then press **Rerun setup**. To archive a workspace that failed to create, press **Archive workspace**.

## Workspaces are named from the first words of the task

Korev names workspaces and Ask chats with Claude Haiku through the `claude` CLI. Without `claude`, or with **Settings → Git → Name workspaces from the task** off, it uses the first words of the task.

## My MCP servers are missing

Korev has no MCP settings of its own. Each agent uses the MCP servers from its own config. Add them with `claude mcp` or in Codex's `config.toml`.

## Two workspaces use the same port

Use `$KOREV_PORT` in your run scripts instead of a fixed port. See [Environment variables](./environment-variables.mdx#ports).

## Spotlight will not turn on

The root checkout must be clean, with no merge or rebase in progress. Commit or stash your changes in the main checkout first.

## The phone cannot reach Korev

The phone must be on the Tailscale network that you signed Korev in to. This can be different from the network of the Mac's Tailscale app. Check that `korev-<your Mac's name>` shows in the device list of the phone's Tailscale app. See [How Korev uses Tailscale](./remote-access.mdx#how-korev-uses-tailscale).

If **Settings → Remote access** shows **Sign in** again, Tailscale wants you to sign in again. This happens when the device key expires, after 180 days by default. To stop it, turn off key expiry for Korev's device in the Tailscale admin console.
