## What the agent can do

- It reads a shared checkout of each repository's default branch, at `<workspaces location>/<repo>/.ask`. All Ask chats for a repository use the same checkout.
- It cannot change files. Claude Code runs without its edit tools. Codex runs in its read-only sandbox.
- Before it runs a command, Korev asks you. This lets it do things outside the checkout with your approval, like posting a pull request review with `gh`. To let Ask chats run commands without asking, turn off **Ask before tool calls** and turn on **Ask chats follow the same behavior** in **Settings → Agents**.
- Plan mode is not available in Ask.

One Ask chat can cover several repositories. Pick them in the repository picker at the top of the chat. The picker lists up to three **Recent** repositories first, then the rest by name.

**New Ask** in the sidebar starts with no repository picked, and **Ask about** on a repository's row picks that repository. To ask a general question, send it without picking a repository. The agent then runs in an empty folder, `<workspaces location>/.ask`, and answers without code. An Ask chat without a repository has no **Start workspace** button.

Korev titles each Ask chat with Claude Haiku after your first message, so you can find it later in the sidebar:

- An Ask chat about one repository sits in that repository, under **Asks**. Click **Asks** to fold the list.
- An Ask chat about two or more repositories sits in **Across repos**, above the repositories. Its row shows the icon and name of each repository.
- An Ask chat without a repository sits in **No repository**, after the repositories.

Each list puts the chat with the latest message first and shows how long ago each chat had its last message. When an Ask chat waits for you, it also shows in **Waiting for you**.

## Review a pull request

Press **Review a pull request** on the Ask page, press ⌘⇧R, or choose **Review a pull request…** in the command palette. Pick a pull request, or paste its link. Korev opens a new Ask about that pull request's repository, with `Review pull request #<number> <title>.` already in the composer. If the repository has a [Code review prompt](../guides/configure-your-repository.mdx#prompts), Korev adds it after that line.

Add what to look at, such as "check the error handling", or type `/` to run a review skill. Then send it. The agent reads the pull request with `gh pr view` and `gh pr diff`. To post the review on GitHub, ask the agent to do it. You approve the `gh` command first.

To understand a pull request before you review it, use [Explain a pull request](../guides/explain-a-pull-request.mdx).

## Start a workspace from an Ask chat

When you are ready to build what you discussed, press **Start workspace**. The new workspace's chat starts with the whole Ask conversation, and its agent continues from there. If the agent wrote a plan, the new chat starts with that plan. The Ask chat moves into the workspace: once the conversation is copied, Korev removes the Ask chat from the sidebar. If Korev cannot create the workspace, the Ask chat stays.

If the Ask chat covers several repositories, the button is **Start workspaces**. Korev creates one [linked workspace](./linked-workspaces.mdx) per repository.
